# ADR-0001：以 ADR 記錄架構決策

- 狀態：採納
- 日期：2026-09-26

## 背景

YACS 以開源專案方式開發，規格包（`docs/spec/`）由產品負責人撰寫，實作過程中必然出現
規格未涵蓋、互相衝突或需依環境調整的地方。若只改程式而不留紀錄，後續貢獻者無法判斷
某個行為是刻意設計還是疏漏。

## 決策

- 所有影響資料模型、安全邊界、對外契約、依賴選型或部署拓撲的決策，都寫成 ADR。
- ADR 一旦採納即不修改內容；改變決策時新增 ADR 並標示取代關係。
- 規格文件同步更新，並在 `docs/spec/CHANGELOG.md` 記錄與原始規格包（v1.0.0）的差異。

## 影響

- 規格與程式的差異有跡可循；review 時可直接引用 ADR 編號。
